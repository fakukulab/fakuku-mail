## FAKUKU Mail 1.0.10

- **본문 이미지 붙여넣기** — 붙여넣은 이미지 데이터를 메일에 저장해 작성 중이거나 초안을 다시 열었을 때 이미지가 표시되도록 개선했습니다.
- **메일 간 이미지 드래그** — 설정에서 **본문 그림을 일반 첨부파일로 보내기**를 끄면 다른 메일의 이미지를 새 메일 본문의 원하는 위치로 끌어 놓고 본문에 포함해 보낼 수 있습니다.

macOS 26 이상 · [사용법](https://mail.fakukulab.com/help.html)

---

- **Pasting images** — Pasted image data is saved in the message so images display while composing and when reopening drafts.
- **Dragging images between messages** — Turn off **Send inline images as regular attachments** to drop an image from another message into the compose body and send it inline.

Requires macOS 26 or later · [Help](https://mail.fakukulab.com/help-en.html)
