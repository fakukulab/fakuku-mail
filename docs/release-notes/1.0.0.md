## FAKUKU Mail 1.0.0

회사의 Microsoft 365(Exchange Online)와 iCloud, Gmail을 한 창에서 쓰는 맥 메일 앱의 첫 정식 배포입니다.

- 계정 여러 개: Exchange(Microsoft 로그인), iCloud·Gmail(앱 암호). 모든 받은 편지함, 보낼 계정 고르기
- 한글 첨부 파일명과 본문 그림을 보내기 전에 바로잡는 첨부 보정
- 대화 묶기와 대화 내역, 새 메일 즉시 알림(iCloud·Gmail), 오프라인 읽기
- 개별 발송, 서명, 규칙·자동 응답(Exchange), 회의 초대와 맥 캘린더
- 메일 활동 보호(추적 픽셀 차단), 메일상자 가져오기·내보내기(mbox)
- Siri와 단축어, 한국어·영어
- 받은 메일의 첨부를 끌어 새 메시지에 첨부

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html
