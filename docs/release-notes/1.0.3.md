## FAKUKU Mail 1.0.3

- **iCloud·Gmail 회의 초대**: iCloud·Gmail 계정으로 받은 회의 초대에도 Exchange처럼 일시·장소와 수락·미정·거절 단추가 보입니다. 답하면 주최자에게 응답을 보내고, 수락·미정이면 맥 캘린더에 넣습니다. 누군가 회의에 답하거나 회의를 취소한 메일은 누가 어떻게 답했는지와 회의 제목·일시·장소를 보여 주고, 붙은 일정 파일은 invite.ics로 보입니다.
- **맥 캘린더**: 주최자가 회의 시각·제목·장소를 바꾼 뒤 다시 수락하거나 메시지 > 맥 캘린더에 추가(⌥⌘K)를 누르면, 앱이 넣었던 일정을 새 내용으로 고칩니다. 이미 맥 캘린더에 있는 회의는 메일을 다시 열어도 "맥 캘린더에 있음"으로 보입니다.
- **자동 업데이트**: 1.0.2를 쓰고 있다면 이 버전은 자동으로 설치됩니다.

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html

---

- **iCloud and Gmail meeting invitations**: invitations received in iCloud and Gmail accounts now show the date, location, and Accept / Tentative / Decline buttons, just like Exchange. Your response is sent to the organizer, and accepted or tentative meetings are added to Calendar. Replies and cancellations show who responded and the meeting’s title, date, and location, and the attached calendar file appears as invite.ics.
- **Calendar**: if the organizer changes a meeting’s time, title, or location, accepting again or choosing Message > Add to Calendar (⌥⌘K) updates the event FAKUKU Mail added. Meetings already in Calendar show “In Calendar” when you open the message again.
- **Automatic updates**: if you’re using 1.0.2, this version installs automatically.

Requires macOS 26 or later. Help: https://mail.fakukulab.com/help-en.html
