## FAKUKU Mail 1.0.7

- **Outlook 같은 규칙**: 설정 > 규칙이 맥 Mail처럼 표와 추가·편집·복제·제거 단추로 바뀌었습니다. 조건·동작·예외를 여러 개 넣고, 차례를 바꾸고, 메일에서 바로 규칙을 만들 수 있습니다. 규칙을 저장하면 받은 편지함의 메일에도 적용할지 묻습니다.
- **스마트 메일상자**: 최근 메일만이 아니라 모든 폴더의 모든 메일에서 찾습니다 (iCloud·Gmail은 보낸 사람·제목 일부와 한글도). 한 번 찾은 결과를 저장해 두고 새로 받은 메일만 더하므로 앱을 열 때마다 오래 찾지 않습니다. 새로 고침을 누르면 처음부터 다시 찾습니다.
- **읽음 표시가 바로**: 메일을 열면 목록의 파란 점, 사이드바 수, Dock 배지가 바로 바뀌고, 새로 고침이 끼어도 다시 읽지 않음으로 돌아가지 않습니다. '읽음으로 표시' 동작 설정은 없앴습니다 (늘 바로).
- **닫을 때 저장할지 묻기**: 쓰던 메일 창을 닫으면 "메시지를 임시 저장하겠습니까?"에서 저장·저장하지 않음·취소를 고릅니다. 화면의 '초안'은 '메시지'로 부릅니다 (메시지 저장, 메시지 이어서 쓰기).
- **오프라인 작성**: 인터넷이 없어도 쓰는 메일이 이 Mac에 남고, 연결되면 임시 보관함에 올라갑니다.
- **메시지 서체**: 새 메시지·답장과 보낸 메일이 설정 > 서체 및 색상의 메시지 서체와 크기로 보입니다.
- **메일상자 메뉴**: 메일상자를 오른쪽 클릭하면 즐겨찾기·내보내기·동기화·계정 정보 등을 고릅니다. 작성할 때 편집 메뉴에 인용문으로 붙여넣기·스타일 일치 등이 생겼습니다.
- **고친 것**: 받는 사람이 수백 명인 메일을 열면 사이드바와 목록이 사라지던 문제 ('외 N명'으로 펼칩니다), 규칙 편집 중 줄을 빼면 앱이 꺼지던 문제, 잠자기에서 깬 뒤 iCloud·Gmail 연결이 끊기면 앱이 꺼지던 문제.

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html

- **Outlook-style rules**: Settings > Rules now has a table with Add, Edit, Duplicate, and Remove buttons, like Mail. Rules can have several conditions, actions, and exceptions, can be reordered, and can be made right from a message. When you save a rule, FAKUKU Mail asks whether to apply it to messages in your Inbox.
- **Smart Mailboxes**: they search all mail in every folder, not only recent mail (for iCloud and Gmail, also parts of a sender or subject, including Korean). Results are kept, so only new mail is searched when the app opens. Click Refresh to search everything again.
- **Read at once**: opening a message updates the blue dot, the sidebar count, and the Dock badge right away, and a refresh no longer brings back the unread state. The “Mark as read” setting is gone (always right away).
- **Ask on close**: closing a message you were writing asks “Do you want to save this message as a draft?” with Save, Don’t Save, and Cancel.
- **Write offline**: messages you write without internet stay on this Mac and go to Drafts when you’re back online.
- **Message font**: new messages, replies, and sent mail use the message font and size from Settings > Fonts & Colors.
- **Mailbox menu**: right-click a mailbox for Favorites, Export, Synchronize, Account Info, and more. The Edit menu in the compose window adds Paste as Quotation and Paste and Match Style.
- **Fixes**: opening a message with hundreds of recipients no longer pushes the sidebar and list away (it shows “and N more”); removing a line while editing a rule no longer quits the app; losing the iCloud or Gmail connection after sleep no longer quits the app.

Requires macOS 26 or later. Help: https://mail.fakukulab.com/help-en.html
