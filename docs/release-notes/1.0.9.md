## FAKUKU Mail 1.0.9

- **답장·전달 표시**: 메일 목록에서 답장한 메일은 ↩, 전체 답장한 메일은 ↩↩, 전달한 메일은 ↪ 회색 화살표가 제목 줄 왼쪽에 붙습니다. Outlook이나 웹에서 한 답장도 보이고, FAKUKU Mail에서 보낸 답장은 Outlook에도 답장함으로 보입니다.
- **전체 답장 확인**: 받는 사람·참조·숨은 참조를 합쳐 두 명 이상일 때만 "전체 답장으로 보내겠습니까?"를 묻습니다. 한 명이면 바로 보냅니다.
- **업데이트**: 앱을 열 때 새 버전을 한 번 확인합니다. 새 버전이 있으면 창이 뜨고, "업데이트 설치"를 누르면 받아서 설치한 뒤 다시 켭니다. "나중에"를 누르면 다음에 앱을 열 때 다시 묻습니다.

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html

---

- **Replied and forwarded marks**: in the message list, a gray arrow left of the subject shows messages you replied to (↩), replied to all (↩↩), or forwarded (↪). Replies made in Outlook or on the web show too, and replies sent from FAKUKU Mail show as replied in Outlook.
- **Reply All check**: FAKUKU Mail asks “Send this as Reply All?” only when To, Cc, and Bcc add up to two or more people. With one person it sends right away.
- **Updates**: FAKUKU Mail checks for a new version once when it opens. If there is one, a window appears; click Install Update to download, install, and relaunch. Click Later and it asks again the next time you open the app.

Requires macOS 26 or later. Help: https://mail.fakukulab.com/help-en.html
