## FAKUKU Mail 1.0.2

- **여러 통을 한꺼번에 읽음으로 표시할 때 빨라졌습니다**: Exchange 계정에서 안 읽은 메일 여러 통을 골라 읽음·읽지 않음으로 바꾸면 오래 걸리고 CPU 사용량이 크게 오르던 문제를 고쳤습니다. 이제 맥 Mail처럼 누르는 즉시 표시가 바뀌고, 서버에는 뒤에서 묶어서 보냅니다. 메일상자 > 모든 메시지를 읽음으로 표시, iCloud·Gmail 계정도 같습니다.
- **메뉴 이름**: 메뉴와 도구 막대에 할 일 하나만 보입니다. 읽지 않은 메일을 고르면 "읽음으로 표시", 읽은 메일을 고르면 "읽지 않음으로 표시".
- **"읽지 않음" 필터**: 필터를 켠 채 메일을 읽음으로 바꾸면 읽은 메일이 목록에 남아 있던 문제를 고쳤습니다. 맥 Mail처럼 읽은 메일은 목록에서 빠지고, 지금 보고 있는 메일은 다른 메일로 넘어갈 때 빠집니다.
- **자동 업데이트**: 이제 FAKUKU Mail이 하루에 한 번 새 버전을 확인하고, 새 버전을 받아 두었다가 앱을 끌 때 설치합니다. FAKUKU Mail > 업데이트 확인…으로 바로 확인할 수도 있고, 설정 > 일반 > 업데이트에서 끌 수 있습니다. (이번 1.0.2는 직접 내려받아 설치해 주세요. 다음 버전부터 자동으로 바뀝니다.)

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html

---

- **Faster when marking many messages as read**: marking many Exchange messages as read or unread at once no longer takes a long time or drives CPU usage up. Like Apple Mail, the change now shows instantly and is sent to the server in batches in the background. This also applies to Mailbox > Mark All Messages as Read and to iCloud and Gmail accounts.
- **Menu names**: menus and the toolbar show one action: "Mark as Read" when the selection has unread messages, otherwise "Mark as Unread".
- **Unread filter**: read messages no longer stay in the list while the Unread filter is on. Like Apple Mail, they leave the list right away; the message you’re reading leaves when you move to another one.
- **Automatic updates**: FAKUKU Mail now checks for a new version once a day, downloads it, and installs it when you quit the app. Choose FAKUKU Mail > Check for Updates… to check right away, or turn it off in Settings > General > Updates. (Please download 1.0.2 yourself; later versions update automatically.)

Requires macOS 26 or later. Help: https://mail.fakukulab.com/help-en.html
