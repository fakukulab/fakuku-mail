## FAKUKU Mail 1.0.2

- **여러 통을 한꺼번에 읽음으로 표시할 때 빨라졌습니다**: Exchange 계정에서 안 읽은 메일 여러 통을 골라 읽음·읽지 않음으로 바꾸면 오래 걸리고 CPU 사용량이 크게 오르던 문제를 고쳤습니다. 이제 서버에 묶어서 보내고 화면은 한 번만 다시 그립니다. 메일상자 > 모든 메시지를 읽음으로 표시, iCloud·Gmail 계정도 같습니다.

macOS 26 이상. 사용법: https://mail.fakukulab.com/help.html

---

- **Faster when marking many messages as read**: marking many Exchange messages as read or unread at once no longer takes a long time or drives CPU usage up. Changes are now sent to the server in batches and the window redraws once. This also applies to Mailbox > Mark All Messages as Read and to iCloud and Gmail accounts.

Requires macOS 26 or later. Help: https://mail.fakukulab.com/help-en.html
